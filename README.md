# BMI-Calculator
A simple student result calculator built with HTML, CSS and JavaScript.

## Live Demo

[Open the BMI Calculator](  https://ahmedhazem111.github.io/BMI-Calculator/)

## Description

A simple and interactive BMI Calculator built with HTML, CSS, and JavaScript. The application allows users to enter their name, height, and weight, then calculates and displays their BMI with a clean and user-friendly interface.
